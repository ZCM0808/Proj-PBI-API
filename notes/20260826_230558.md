  ### 方法 1：一行 Python 命令（推荐，全自动复制到剪贴板）⭐️

  在本地电脑的 PowerShell 或终端中直接运行以下命令：

    python -c "import msal, subprocess; app=msal.PublicClientApplication('ea0616ba-638b-4df5-9119-
  5cf52d6ac0d5'); res=app.acquire_token_interactive(['https://analysis.windows.net/powerbi/api/.
  default']); tok=res['access_token']; subprocess.Popen('clip', stdin=subprocess.PIPE, shell=True).
  communicate(tok.encode('utf-8')); print('\n✅ Power BI Access Token
  已生成并自动复制到剪贴板！可以直接在 Render 网页端 Ctrl + V 粘贴使用。')"

  • 执行效果：
      1. 电脑屏幕会弹出一个微软官方登录小窗口；
      2. 您使用 carman_zhao@vfc.com 完成 Authenticator 验证；
      3. Token 会全自动写入您的 Windows 剪贴板；
      4. 打开 Render 网页端，在 Access Token 输入框按 Ctrl + V 粘贴即可！

  ### 方法 2：使用本地已安装的 Azure CLI / PowerShell

  如果您的本地电脑安装了 Azure CLI，直接在 PowerShell 运行：

    az account get-access-token --resource https://analysis.windows.net/powerbi/api --query accessToken
  -o tsv | Set-Clipboard

  │ 该命令会获取您当前的个人 Power BI Access Token 并直接存入剪贴板。
